# ✅ TaskFlow - Vanilla JS ToDo App

A sleek, performance-oriented ToDo application built with **Vanilla JavaScript** and **DOM Manipulation**. TaskFlow features real-time progress tracking, persistent dark mode, and a mobile-first design.

## 📖 Project Overview

TaskFlow is a minimalist task management tool built to demonstrate advanced DOM manipulation and browser storage techniques. Unlike basic todo lists, this app calculates progress dynamically and ensures your theme preference (Light/Dark) stays consistent across browser sessions without needing a backend.

---

## ✨ Key Features

* **🌓 Persistent Dark Mode:** Toggle between themes seamlessly. Uses `localStorage` and a blocking script in the `<head>` to prevent "theme flashing" on page load.
* **📊 Dynamic Progress Tracking:** A visual progress bar and counter (`0/0 done`) that updates instantly as you add or complete tasks.
* **🛠️ Pure DOM Logic:** Entirely built without frameworks (No React/Vue). Manages state, event listeners, and element creation through native JavaScript.
* **🗑️ Bulk Cleanup:** Features a "Clear Completed" action to quickly prune finished tasks.
* **📱 Modern UI:** Styled with **Tailwind CSS v4** and **DaisyUI v5** for a professional, responsive look.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure.
* **Vanilla JavaScript (ES6+):** For state management and DOM updates.
* **Tailwind CSS (v4):** Utility-first styling.
* **DaisyUI (v5):** UI component library for the theme toggle, progress bars, and buttons.
* **Google Fonts:** Inter for clean, modern typography.

---
